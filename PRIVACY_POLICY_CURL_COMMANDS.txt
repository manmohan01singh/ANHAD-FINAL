🔍 TROUBLESHOOTING

Issue: Connection Refused
→ Solution: Start backend server
  Command: node backend/server.js
  Or:      npm start

Issue: 404 Not Found  
→ Solution: Check server is serving frontend directory
  Verify CONFIG.FRONTEND_ROOT in backend/server.js

Issue: CORS Error
→ Solution: Server allows all origins in dev mode
  Check ALLOWED_ORIGINS environment variable for production
